# GC010 language-aware analytics

The homepage, calendar, dietary and directions pages report the language actually displayed. German retains the canonical page path; English uses `/en/`, `/en/kalender/`, `/en/ernaehrung/` or `/en/anfahrt/` as analytics-only paths. These are not navigable website URLs. The existing canonical URLs and website text are unchanged.

The deferred analytics coordinator listens to the shared language initialization before the deferred GoatCounter loader runs. The loader uses `no_onload`; the coordinator manually sends the first visible language and binds existing click tracking once. A Set limits observations to one per page/language pair in each document, including repeated switches and persisted-page signals. Reloads can send a new request; normal GoatCounter Sessions counting determines report increments. No `no_session` override or language-toggle event is introduced. Delayed libraries observe the current language without replaying transient switches. Tracking failure must not affect the website.
